Dataset: Simulación de Propagación de Daños en Motores de Aviación

Para el desarrollo de las visualizaciones de este portafolio, se utiliza una única fuente de datos con dos enfoques de análisis separados. Los datos provienen de una simulación termodinámica de motores de turbina de gas de aviones comerciales[cite: 3, 4].

Características Principales de los Datos:

  • Origen: Los datos fueron generados originalmente como un desafío para la competencia de datos Prognostics and Health Management (PHM'08)[cite: 11].
  • Herramienta de Simulación: Se utilizó la herramienta C-MAPSS (Commercial Modular Aero-Propulsion System Simulation), la cual simula un motor turboventilador grande comercial con un empuje de 90,000 lb[cite: 85, 87, 88].
  • Metodología de Falla: El modelo simula la propagación de daños imponiendo una tasa de cambio exponencial para la pérdida de flujo y eficiencia[cite: 5]. Esta degradación continuó simulándose hasta que un "índice de salud" llegó a cero, definiendo así el criterio de falla del motor[cite: 8, 9].
  • Variables Monitoreadas: El conjunto de datos incluye salidas de series de tiempo (medidas en ciclos) de sensores típicamente disponibles en este tipo de motores[cite: 10]. En total, se registraron 21 variables de estado (como temperaturas, presiones y velocidades físicas del núcleo) de las 58 disponibles en el modelo[cite: 115, 140].
  • Condiciones Operativas: Las simulaciones se ejecutaron bajo 6 combinaciones diferentes de condiciones de vuelo, variando la altitud (de 0 a 42,000 pies), el número de Mach (0 a 0.84) y el ángulo del resolver del acelerador (TRA)[cite: 372, 425].
